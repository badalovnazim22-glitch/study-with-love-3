# Study with Love 2.4

## Что включено
- Розовое оформление календаря и значков разделов в прогрессе.
- В списке тем нет подсказки «Нажмите, чтобы открыть тему».
- Учёт минут занятий по таймеру Pomodoro и отображение времени в разделе «Мой прогресс».
- Отдельная вкладка Pomodoro с выбором длительности занятия (15, 25, 30, 45, 60 минут) и перерыва (5, 10, 15 минут).
- Личный дневник успехов с сохранением и удалением заметок на устройстве.
- Раздел «Мне грустно» со случайными милыми изображениями и поддерживающими фразами; изображения хранятся в приложении и доступны офлайн.
- Остальные разделы, напоминания и локальное сохранение прогресса.

## Важно: как заменить проект в GitHub
1. Скачайте и распакуйте архив.
2. В корне репозитория должны находиться папки `.github` и `app`, а также файлы `build.gradle`, `gradle.properties`, `settings.gradle`.
3. Не загружайте ZIP как отдельный файл и не помещайте проект во вложенную папку `Study_with_Love_v4_Cloud_Build`.
4. Замените содержимое корневой папки `app` файлами из архива. Также замените корневые `build.gradle`, `gradle.properties`, `settings.gradle` и `.github/workflows/build-apk.yml`.
5. Откройте GitHub Actions. Workflow `Build Study with Love APK` должен запускать `gradle --no-daemon assembleDebug` из корня репозитория.
6. После успешного запуска скачайте артефакт `Study-with-Love-APK`.

## Сборка
Сборка выполняется GitHub Actions на облачном runner с JDK 17, Gradle 8.9 и Android SDK 35. Локально Android Studio не требуется.

## Данные
Заметки дневника, прогресс и статистика времени сохраняются локально в SharedPreferences приложения. При обновлении APK устанавливайте поверх прежней версии и не удаляйте приложение, чтобы сохранить локальные данные.


## Версия 2.5 — обновления интерфейса и функций
- Плавное появление экранов без резкой белой перезагрузки.
- В Pomodoro можно вручную указать длительность от 1 до 600 минут; пауза вынесена в отдельную кнопку.
- В дневнике можно редактировать сохранённые записи; после сохранения появляется розовая плашка «Запись сохранена».
- Удалён раздел «Мне грустно».
- В «Послание для тебя» добавлена кнопка генерации нового случайного послания.
- В прогрессе учитывается время, пока приложение открыто на экране; минуты сохраняются при сворачивании приложения и обновляются при открытии раздела прогресса.
