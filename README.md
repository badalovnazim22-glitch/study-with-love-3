# Study with Love

**Версия приложения:** 4.1 (versionCode 10)  
**Пакет:** `com.studywithlove.app`  
**Android:** minSdk 23, targetSdk 35

## Сборка APK

APK собирается GitHub Actions при каждом push в `main` или вручную через Actions → Build Study with Love APK. Готовый файл находится в артефакте `Study-with-Love-APK`.

## Постоянная подпись APK — настройка один раз

Чтобы устанавливать новые APK поверх предыдущей версии без удаления данных, все сборки должны быть подписаны одним и тем же закрытым ключом.

1. Скачайте файл `study-with-love-upload.jks`, переданный отдельно.
2. Откройте GitHub → репозиторий → Settings → Secrets and variables → Actions → New repository secret.
3. Создайте секреты:
   - `ANDROID_KEYSTORE_BASE64` — Base64-содержимое файла keystore. В PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("study-with-love-upload.jks"))`.
   - `ANDROID_KEYSTORE_PASSWORD` — пароль keystore, переданный вместе с файлом.
   - `ANDROID_KEY_ALIAS` — `studywithlove`.
   - `ANDROID_KEY_PASSWORD` — пароль ключа (в этой конфигурации такой же, как пароль keystore).
4. Запустите workflow заново. Предупреждение «Permanent signing is not configured» должно исчезнуть.

**Важно:** секреты нельзя записать через доступное GitHub-подключение этой сессии, поэтому их нужно добавить вручную. Пока секреты не добавлены, Actions продолжит собирать APK временным debug-ключом, и обновление поверх установленного приложения не гарантируется.

**Переход на новый постоянный ключ:** APK, ранее собранные на временных runner-ключах, нельзя обновить новой подписью Android. Перед первой установкой постоянной сборки экспортируйте резервную копию из приложения. Возможно, придётся удалить старую версию, установить APK с постоянной подписью и восстановить данные из резервной копии. После этого сборки с тем же keystore будут обновляться поверх.

## Учёт занятий и данные

- Прогресс и личные данные хранятся локально в SharedPreferences.
- «Я позанималась сегодня» отмечает только учебный день и не выставляет теме 100%.
- Время нахождения приложения на экране показывается отдельно как время в приложении и не увеличивает серию.
- Завершённая Pomodoro-фокус-сессия отмечает учебный день и отправляет уведомление.
- Резервная копия при экспорте перезаписывает выбранный файл.
