# Study with Love

**Версия приложения:** 4.64 (versionCode 73)  
**Пакет:** `com.studywithlove.app`  
**Android:** minSdk 23, targetSdk 35

## Дизайн интерфейса

- Основная тема приложения — светлая лавандовая палитра с глубоким фиолетовым акцентом, мягкими поверхностями и крупными скруглениями.
- Основная навигация использует единый набор контурных иконок; экран ИИ-репетитора следует той же цветовой системе.

## Сборка APK

APK собирается GitHub Actions при каждом push в `main` или вручную через Actions → Build Study with Love APK. Готовый файл находится в артефакте `Study-with-Love-APK`.

## Подпись APK и обновления

GitHub Actions использует настроенный постоянный keystore через repository secrets. Новые сборки подписываются тем же ключом, поэтому их можно устанавливать поверх предыдущей версии без удаления приложения. Не публикуйте keystore и пароли. Перед крупными обновлениями рекомендуется экспортировать резервную копию из приложения.

## Учёт занятий и данные

- Прогресс и личные данные хранятся локально в SharedPreferences.
- «Я позанималась сегодня» отмечает только учебный день и не выставляет теме 100%.
- Время нахождения приложения на экране показывается отдельно как время в приложении и не увеличивает серию.
- Завершённая Pomodoro-фокус-сессия записывает минуты по дате окончания, отмечает учебный день и начисляет награды даже при завершении в фоне.
- Резервная копия при экспорте перезаписывает выбранный файл.

## Банк вопросов и резервные копии

- Банк находится в `app/src/main/assets/question_bank.json`; в нём 328 заданий для 41 темы.
- В настройках доступны 12 цветовых тем и 6 системных шрифтов; акцентные элементы, индикаторы и ползунки подстраиваются под выбранную тему.
- В разделе экзамена можно выбрать темы, которые учитываются в учебном прогрессе и автоматическом плане.
- Собственные карточки хранятся локально, проходят проверку полей и добавляются в мини-тесты соответствующей темы.
- Режим «Напарник по учёбе» обменивается недельными результатами и стикерами через код, без регистрации и фоновой синхронизации.
- Варианты ответов перемешиваются при показе вопроса; в заданиях «верно/неверно» есть как истинные, так и ложные утверждения.
- Звуки завершения Pomodoro и правильного ответа генерируются локально из встроенного кода приложения; для них не требуется интернет или внешний аудиосервис.
- В резервной копии сохраняются пользовательские данные и остатки минут; временное состояние работающего таймера в копию не включается.

## ИИ-репетитор (Cloudflare Workers AI)

- Android-приложение отправляет HTTPS-запросы на собственный Cloudflare Worker с маршрутом `/chat`. Секреты провайдера не хранятся в APK.
- Серверный код находится в `cloudflare/ai-worker.js`; конфигурация Wrangler — `cloudflare/wrangler.toml`.
- Worker использует Cloudflare Workers AI через binding с именем `AI` и модель `@cf/zai-org/glm-4.7-flash`. В Cloudflare Worker нужно добавить AI binding: variable name `AI`, Cloudflare AI resource.
- Для публикации через Wrangler из папки `cloudflare`: `npx wrangler deploy`. Перед деплоем проверьте совместимость модели и доступность Workers AI в аккаунте Cloudflare.
- Ограничение запросов настраивается binding `RATE_LIMITER`; в конфигурации задан лимит 12 запросов в минуту на IP. Локальный fallback внутри isolate не заменяет edge rate limiting.
- В настройках ИИ можно по желанию включить сохранение переписки на устройстве. По умолчанию история не сохраняется; выключение настройки удаляет локальную копию диалога.
- Контекст темы и неверного ответа из мини-теста передаётся репетитору. Если интернет недоступен, для заданий из банка приложение показывает локальный разбор и правильный ответ без обращения к сети.
- Не отправляйте в ИИ пароли, адреса и другие личные данные. Не добавляйте API-ключи в Android-код, README или репозиторий.
