# Study with Love 3.0 — Minimal Edition

Полный Android-проект для сборки через GitHub Actions.

## Сохранённая математическая база

В `MainActivity.java` сохранены все 4 исходных раздела и темы:
1. Натуральные числа и действия с ними (1.1–1.8)
2. Обыкновенные дроби (2.1–2.10)
3. Десятичные дроби (3.1–3.11)
4. Процент (4.1–4.4)

Также сохранены отметка прогресса, календарь занятий, напоминания, Pomodoro, дневник успехов и послания.

## Новые разделы 3.0

- Мой цветочек — росток/листья/бутон/цветок/букет по числу дней занятий.
- Коллекция достижений — награды за дни занятий, завершённые темы и минуты.
- Письмо себе в будущее — локальное сохранение писем с датой открытия.
- Календарь привычек — использует существующий календарь и статистику прогресса.
- Атмосфера учёбы — выбор и сохранение визуального режима (дождь, кафе, природа, библиотека).

Примечание: экран атмосферы пока хранит выбор режима и показывает визуальное описание; аудиофайлы фоновых звуков в этом проекте не включены.

## Сборка

В корне репозитория должен находиться `.github/workflows/build-apk.yml`.
GitHub Actions собирает APK командой `gradle assembleDebug`; результат: `app/build/outputs/apk/debug/app-debug.apk`.

Версия приложения: 3.0 (versionCode 8). Сохранены `applicationId` и SharedPreferences-ключи исходной версии, чтобы обновление поверх установленного приложения могло сохранить локальный прогресс.
