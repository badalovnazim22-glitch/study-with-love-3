# Study with Love — справка по версии 3.0

Этот файл сохранён как историческая заметка. Текущая версия проекта указана в корневом README и в `app/build.gradle`.

## Актуальная структура учебных тем

В приложении 41 встроенная тема в четырёх разделах:
1. Натуральные числа и действия с ними — 1.1–1.10.
2. Обыкновенные дроби — 2.1–2.12.
3. Десятичные дроби — 3.1–3.13.
4. Процент — 4.1–4.6.

Банк мини-тестов находится в `app/src/main/assets/question_bank.json`. Он содержит задания типов «выбери ответ», «впиши ответ», «верно/неверно» и «найди ошибку». Варианты ответа перемешиваются перед показом. Вопросы «верно/неверно» включают как верные, так и ложные утверждения.

## Атмосфера учёбы и аудио

Фоновые звуки дождя, кафе, природы и библиотеки загружаются из Wikimedia Commons и зацикливаются. Для воспроизведения требуется интернет. Источники и лицензии указаны в `AUDIO_CREDITS.md`.

## Сборка и данные

- GitHub Actions собирает APK при push в `main`.
- Подпись APK настроена через постоянный keystore в GitHub Actions secrets; новые сборки подписываются стабильным ключом.
- Прогресс хранится локально в SharedPreferences.
- Перед обновлением рекомендуется экспортировать резервную копию в приложении.
